# MVP 开发任务拆分

## 里程碑 M0：项目初始化

- [x] 建立 Vue 3 + TypeScript + Vite 工程。
- [x] 配置 ESLint、Prettier 和格式化检查。
- [ ] 配置路径别名和环境变量规范。
- [x] 配置基础 CI：安装、类型检查、Lint、测试、构建。
- [x] 建立页面骨架、路由和设计令牌。
- [x] 配置中英文语言包、语言切换和浅色/深色主题。

## 里程碑 M1：核心图片流程

- [x] 文件选择和拖拽上传。
- [x] 文件校验和限制提示。
- [x] 任务模型和状态机。
- [x] Worker 图片处理。
- [x] 参数面板。
- [x] 结果列表、单项下载、批量 ZIP。
- [x] 清除、重试和错误恢复。

## 里程碑 M2：产品化页面

- [x] 首页和三个 SEO 工具页。
- [x] FAQ、关于、隐私、条款、404。
- [x] 移动端响应式布局。
- [x] 中英文页面内容、动态文案和 SEO 元数据。
- [x] 浅色/深色模式、系统主题跟随和对比度验证。
- [x] 可访问性和空状态完善。
- [x] 统一 SVG 图标和焦点样式。

## 里程碑 M3：发布与变现准备

- 广告容器和配置开关。
- 分析事件和错误监控适配器。
- sitemap、robots、canonical 和结构化元数据。
- 站点部署、域名、HTTPS 和回滚。
- Lighthouse、跨浏览器和 E2E 验收。

## 优先级规则

- P0：不完成则不能上线。
- P1：影响体验，但可以首发后补充。
- P2：验证流量和用户需求后再决定。
