# MVP 开发任务拆分

## 里程碑 M0：项目初始化

- 建立 Vue 3 + TypeScript + Vite 工程。
- 配置 ESLint、格式化、路径别名和环境变量。
- 配置基础 CI：安装、类型检查、Lint、测试、构建。
- 建立页面骨架、路由和设计令牌。
- 配置中英文语言包、语言切换和浅色/深色主题。

## 里程碑 M1：核心图片流程

- 文件选择和拖拽上传。
- 文件校验和限制提示。
- 任务模型和状态机。
- Worker 图片处理。
- 参数面板。
- 结果列表、单项下载、批量 ZIP。
- 清除、重试和错误恢复。

## 里程碑 M2：产品化页面

- 首页和三个 SEO 工具页。
- FAQ、关于、隐私、条款、404。
- 移动端响应式布局。
- 中英文页面内容、动态文案和 SEO 元数据。
- 浅色/深色模式、系统主题跟随和对比度验证。
- 可访问性和空状态完善。
- 统一 SVG 图标和焦点样式。

## 里程碑 M3：发布与变现准备

- 广告容器和配置开关。
- 分析事件和错误监控适配器。
- sitemap、robots、canonical 和结构化元数据。
- 站点部署、域名、HTTPS 和回滚。
- Lighthouse、跨浏览器和 E2E 验收。

## 优先级规则

- P0：不完成则不能上线。
- P1：影响体验，但可以首发后补充。
- P2：验证流量和用户需求后再决定。
