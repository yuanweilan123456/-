# 文件工具箱扩展方案

## 产品定位

PixelForge 从“图片处理工具”升级为“隐私优先的文件工具箱”。首期仍坚持本地处理，不上传用户文件。

## 首期工具矩阵

| 工具              | 首期状态 | 处理方式   | 说明                                       |
| ----------------- | -------- | ---------- | ------------------------------------------ |
| 图片压缩          | 已有     | 本地浏览器 | JPG、PNG、WebP                             |
| 图片格式转换      | 已有     | 本地浏览器 | JPG、PNG、WebP                             |
| 图片尺寸调整      | 已有     | 本地浏览器 | 支持保持比例                               |
| PDF 合并          | 新增     | 本地浏览器 | 多个 PDF 合并为一个                        |
| PDF 拆分          | 新增     | 本地浏览器 | 按页拆成多个 PDF，并打包 ZIP               |
| 图片转 PDF        | 新增     | 本地浏览器 | JPG、PNG、WebP 图片生成 PDF                |
| DOCX 转 HTML/文本 | 新增     | 本地浏览器 | 适合内容提取和预览，复杂排版不保证完全还原 |
| 图片生成 PPTX     | 新增     | 本地浏览器 | 每张图片生成一页 PPTX                      |

## 暂不承诺的功能

PDF ↔ Word、PDF ↔ PPT、Word ↔ PPT 的高保真双向互转不纳入纯前端首期承诺。此类转换需要复杂的版式解析、字体替换、表格/图形/批注处理，后续应通过独立转换服务或专业引擎实现，并在用户明确同意后上传文件。

## 扩展原则

- 每个工具必须有独立 URL、说明、限制和错误恢复。
- “本地处理”只在文件确实没有发送到服务器时展示。
- 工具状态、下载和广告容器使用统一组件规范。
- 未来增加后端处理时，页面状态层不应感知具体转换引擎。
