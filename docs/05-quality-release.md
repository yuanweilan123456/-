# 质量、合规与发布方案

## 1. 测试策略

### 单元测试

- 文件类型、大小、数量和像素限制。
- 尺寸计算和保持比例。
- 输出格式和质量参数映射。
- 任务状态转换与错误分类。
- 文件名清洗和下载名称。

### 组件测试

- 上传区的选择、拖拽、拒绝和键盘操作。
- 参数设置的可用性和边界值。
- 进度、成功、部分失败和全失败状态。
- 广告脚本未加载时的布局稳定性。

### E2E 测试

- 单张 JPG 压缩并下载。
- 批量图片处理并下载 ZIP。
- 不支持格式和超大文件的错误恢复。
- 移动端 viewport 下完整操作。
- 直接访问 SEO 页面、政策页面和 404 页面。

### 手工验收

- Chrome、Edge、Safari、Firefox。
- iOS Safari、Android Chrome。
- 375px、768px、1440px 宽度。
- 键盘操作、屏幕阅读器基本顺序、减少动态效果。
- 慢网、无网络、广告阻断和存储受限场景。

## 2. 发布门槛

- P0 验收标准全部通过。
- 没有阻断级或高优先级未解决缺陷。
- 构建、类型检查、Lint、单元测试和 E2E 测试通过。
- Lighthouse 指标达到项目目标。
- 隐私政策、条款、联系方式和错误页面已上线。
- 广告默认可关闭，未配置广告账号时不会显示空白或报错。
- 域名、HTTPS、站点地图、robots 和站长工具验证完成。

## 3. 变现方案

首发只设置少量广告位：工具区下方一个、内容区一个；不在上传按钮、下载按钮或错误按钮旁伪装广告。广告脚本异步加载，并保留稳定高度。

广告平台需在目标地区、主体资格和网站内容准备完成后申请。平台通常要求原创、有价值的内容，并可能因政策、地区或广告主偏好限制展示；因此 MVP 的商业目标首先是建立可用流量，而不是立即依赖广告收入。

## 4. 发布后运营

- 每周检查错误监控和处理失败率。
- 每两周检查搜索页面的收录、点击和页面质量。
- 每月复核广告对完成率和留存的影响。
- 只基于真实用户问题新增工具页，不批量生成低价值页面。
