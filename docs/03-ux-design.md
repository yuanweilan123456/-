# UX/UI 设计基线

## 1. 设计方向

采用“可信、轻量、内容优先”的工具型 Web 风格。界面重点是让用户立刻看到上传入口、支持格式、隐私承诺和处理结果；不使用装饰性复杂动效，不让广告抢夺视觉层级。中英文切换和浅色/深色模式属于全局能力，不能只覆盖首页。

## 2. 信息架构

```text
首页
├── 核心图片工具
├── 功能说明
├── 相关工具链接
├── 常见问题
└── 页脚：关于 / 隐私 / 条款 / 联系
工具落地页
├── 页面标题与一句话价值说明
├── 工具操作区
├── 使用步骤
├── 适用场景与限制
├── FAQ
└── 相关工具
```

## 3. 核心页面状态

1. 初始空状态：上传入口、支持格式、大小限制、隐私说明。
2. 已选择：文件列表、参数面板、移除和开始处理。
3. 处理中：进度、已完成数量、禁止重复提交。
4. 部分成功：成功和失败分组、单项重试、下载入口。
5. 全部完成：结果摘要、批量下载、重新处理。
6. 错误：原因、解决建议和重试操作。

## 4. 设计令牌

- 主色：`#4F46E5`，用于主要 CTA 和链接。
- 成功色：`#15803D`，搭配文字/图标，不单独依赖绿色。
- 警告色：`#B45309`。
- 错误色：`#B91C1C`。
- 正文：`#172033`；辅助文字：`#526078`；背景：`#F7F8FC`；表面：`#FFFFFF`。
- 深色主题背景：`#0F172A`；深色表面：`#172033`；深色正文：`#F8FAFC`；深色辅助文字：`#CBD5E1`。
- 圆角：卡片 16px，控件 10px，标签 999px。
- 间距：4px 基础单位，优先使用 8/16/24/32/48px。
- 正文最小字号 16px；正文行高 1.5–1.75。
- 桌面内容最大宽度约 1120px；移动端优先，断点 375/768/1024/1440。

## 5. 交互原则

- 每个页面只设一个主要操作。
- 拖拽不是唯一入口，必须提供可点击选择按钮。
- 所有异步操作显示即时反馈；超过约 1 秒显示进度或骨架状态。
- 按钮、图标按钮和文件列表操作满足至少 44×44px 点击区域。
- 动画控制在 150–300ms，并尊重 `prefers-reduced-motion`。
- 图标使用同一套 SVG 图标，不使用 emoji 作为结构化图标。
- 广告位预留固定尺寸，避免内容因广告加载发生跳动。
- 主题切换不依赖颜色反转；两套主题分别验证正文、辅助文字、边框和状态色的对比度。
- 文案长度按英文通常更长来设计，按钮和导航允许自然扩展，不依赖固定宽度截断。
